# Vendored Koinos node files

The files in this directory are used to assemble a per-network node data
directory at runtime (`docker-compose.yml`, `.env`, `config/`).

- `docker-compose.yml`, `common/koinos_descriptors.pb`, `common/rabbitmq.conf`,
  `mainnet/genesis_data.json`, `harbinger/genesis_data.json` are vendored
  unmodified from the official node repository
  [koinos/koinos](https://github.com/koinos/koinos)
  (commit `821674672e699bf56e94d7c0e8bce122e83d1482`, MIT licensed).
- `config.yml` and `.env` are generated by the app
  (`electron/lib/node-manager.js`), based on the repository's
  `config-example/config.yml` and `env.example`, with the block producer
  address, base directory, ports, and compose profiles filled in.
- Docker image tags in `electron/lib/constants.js` follow the versions pinned
  in `env.example` (mainnet) and `harbinger/env.example` (testnet).

To upgrade the node version, refresh these files from the upstream repository
and update the image tags in `electron/lib/constants.js`.
